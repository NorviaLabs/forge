Forge architecture

One agent core for TUI and headless. Live models via LiteLLM SDK worker. SQLite journal for crash-safe resume. Optional session git worktrees so the primary tree stays clean.

Models (production)
Sole live path
LiteLLM worker · Python SDK (not Proxy)
Forge spawns a worker over stdio JSON-RPC. One client covers OpenAI, Anthropic, xAI, and the long tail via LiteLLM model strings. No separate native multi-provider HTTP stack. Connect profiles still use this path.
