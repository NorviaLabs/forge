What changes in Forge

One consistent workspace. Repository and session identity move onto one left-aligned header. Quiet text tabs replace nested tab boxes. The task, activity, and inspector text share a two-column inner inset. The prompt’s top rule and caret identify focus. On the start screen, a centered task group keeps the prompt next to three complete starter tasks; the prompt spans the working surface during a task.

Information appears where it helps. Routine reads and successful commands collapse into a neutral activity summary. Exact commands remain one action away. Changes open in the existing inspector. Failures and pending decisions stay visible. Session attention remains in the header even when the navigator is hidden.

Preserve Forge’s controls. This concept keeps Tab, Shift+Tab, Ctrl+1/2/3, F6, slash commands, and Esc. Clicks use the same state changes. The explicit “Don’t run” default is a proposed approval change. Sample plans report checklist status; they do not authorize tool execution.

At 120 columns, review shows chat and the inspector. At 160 columns, a 24-column navigator also fits. At 80 columns, F6 switches retained chat and diff; the composer stays available. At 80×18, a two-row prompt and shared separators preserve the task, decision controls, and all seven example session states. Distinct blocks use one blank row; labels, list items, and grouped outputs stay together. Focus markers, state words, and +/− diff signs survive monochrome.

“Motion off” respects the operating system’s reduced-motion preference at launch. Mono mode removes semantic colors; wording and glyphs still identify outcomes. Product content uses one monospace size. The terminal title bar, rounded window shell, and this study’s typography belong to the presentation around Forge, not the proposed TUI.
